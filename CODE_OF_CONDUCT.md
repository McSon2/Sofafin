# Code de conduite

## L'esprit

Ce projet est petit et technique. On y vient pour regarder des films sans
friction, et pour écrire du code qui tient. Les échanges y sont directs : une
critique de code porte sur le code, jamais sur la personne qui l'a écrit.

## Ce qu'on attend

- **Dire pourquoi.** Une objection sans raison n'aide personne ; une raison, même
  brève, permet de trancher.
- **Accepter le désaccord technique.** Plusieurs solutions valent souvent mieux
  qu'une, et celle qui n'est pas retenue n'est pas pour autant mauvaise.
- **Écrire pour être lu.** Le français et l'anglais sont acceptés ; la clarté
  compte plus que la forme.

## Ce qui n'a pas sa place

Le harcèlement, les attaques personnelles, les propos discriminatoires, la
divulgation d'informations privées, et l'insistance après un refus argumenté.
