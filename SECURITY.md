# Signaler une faille

Sofafin ne collecte rien et n'expose aucun service : la surface d'attaque se
limite au jeton de session conservé sur l'appareil et aux échanges avec le
serveur que l'utilisateur désigne.

Si vous trouvez une faille — fuite du jeton, requête vers un tiers, contournement
de l'authentification — **n'ouvrez pas de ticket public**. Écrivez à
hello@maximesaltet.com, ou utilisez l'avis de sécurité privé de GitHub
(onglet Security → Report a vulnerability).

Précisez ce que vous avez observé et comment le reproduire. Une réponse suivra
sous une semaine.
